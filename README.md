# VR Fit Companion — Desktop Polished Workout UI

Desktop-only A-Frame workout companion.

## Update
- Starting a workout hides the large workout interface so the 3D coach stays unobstructed.
- The End Workout control remains fixed at the top-left during an active workout.
- Ending the workout restores the compact interface at the top-left.
- Includes the existing exercise animations and desktop front-camera option.

## Run
Open `index.html` in a modern browser. Webcam mode works on HTTPS or localhost after camera permission is granted.
